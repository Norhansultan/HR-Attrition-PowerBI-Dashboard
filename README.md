# HR Attrition Power BI Dashboard

## Overview
An interactive 4-page dashboard that analyzes employee attrition and helps HR spot who is at risk and why.

## Pages
- **Overview**: headline KPIs (total employees, attrition, average age, income, tenure) and workforce breakdowns.
- **Drivers**: what pushes people to leave (overtime, job role, satisfaction, income and more).
- **Employee Insights**: demographics, tenure and compensation by job level.
- **Risk & Recommendations**: risk levels and suggested actions.

## Highlights
- Custom filter panel built with HTML and JavaScript inside Power BI (Department, Job Role, OverTime, Job Level, Gender).
- Dark and light theme toggle.
- Navy and gold design with animated visuals.

## Files
- `HR Attrition.pbix`: the full Power BI report.
- `HR_*_HTML.dax`: the DAX measures that generate each page's HTML/JS visual.
- Screenshots of each page.

## Tools
Power BI, DAX, HTML, CSS, JavaScript
